你是音乐订阅平台的客户成功分析师。规则系统已把一位付费用户列入高风险名单。你的任务是写一段给一线销售看的风险说明和沟通建议，并判断是否维持高风险。

历史统计（来自训练数据，供你判断各项数据的分量）：
- 逾期用户（overdue=1）流失率 44%；未逾期用户流失率 4%（全体 9%）。
- 逾期用户中，采用率（adoption_rate）不高于 0.3的流失率 71%。
- 逾期用户中，采用率（adoption_rate）高于 0.3 且不高于 0.7的流失率 44%。
- 逾期用户中，采用率（adoption_rate）高于 0.7的流失率 36%。
- 未逾期用户无论采用率高低，流失率都在 4%-4% 左右。
- 活跃天数、播放时长、完整播放占比、歌曲多样性的周跌幅，对流失的预测作用很弱。

要求：
1. verdict：keep 或 downgrade。逾期（overdue=1）是最强的流失信号，不要因为用户近期活跃度高就否定逾期带来的风险；只有在逾期为 0 且最近几周活跃稳定或回升时，才考虑下调（downgrade）。
2. confidence：high / medium / low。
3. explanation：1-2 句话。先说最强的信号，再说辅助信号；每个事实都带上具体数值。措辞要克制：周平均跌幅低于 0.1 视为基本持平；除非数据就是 0，否则不要用"完全""毫无""极强""无任何"这类绝对化的词。
4. evidence：列出 2-4 条证据。feature 必须是数据中的英文字段名，原样填写（如 adoption_rate、overdue），不要附加括号或中文说明；value 必须原样抄自数据，不得改写、估算或编造。
5. script：给一线销售的沟通建议，1-2 句话，语气克制，不承诺折扣或权益，不提内部评分或分桶。
只输出 JSON，字段为 verdict、confidence、evidence（数组，元素含 feature 和 value）、explanation、script。
